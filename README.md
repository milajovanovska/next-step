# NEXTSTEP

A personalized study and career navigation platform for highschool students.

## About

NEXTSTEP helps students discover possible career paths and explore study opportunities based on their interests, skills, academic background, preferences, financial constraints, and future goals.

The platform is designed to guide students from self-discovery to concrete study and application planning.

## Main Features

- AI Conversation assessment
- Classic questionnaire assessment
- Personalized student profile
- Career path recommendations
- University and study program exploration
- Study in North Macedonia
- Study abroad
- Scholarships
- Tuition and living cost information
- Accommodation and dorm information
- University and program comparison
- Admission requirements
- Application roadmap
- Document checklist
- Institution contact information
- Personalized student dashboard
- Verified education data
